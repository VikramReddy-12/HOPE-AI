# HOPE

## Human-Oriented Personal Engine

**Created by:** Vikram Reddy

## Vision

HOPE is an intelligent AI assistant that I am building from scratch.

The goal is to create an AI similar to Jarvis that can:

- Talk with users
- Remember information
- Understand voice
- Understand images
- Control the computer
- Learn new skills
- Help with daily tasks
